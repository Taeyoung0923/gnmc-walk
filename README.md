# gnmc-walk
# 가을 수학 산책

경남수학문화관이 경남 초·중·고 수학 담당 교사에게 보내는 2026년 9월 소식지입니다.

경남수학교육체험벨트(본원 1곳, 분원 6곳)의 개별 특성, 학교체험수학 프로그램과 이어지는
수업 연계 방법, 스탬프 투어 안내를 한 장의 웹 문서로 담았습니다.

## 보기

`index.html` 파일 하나로 되어 있습니다. 이미지와 글꼴 설정이 모두 파일 안에 들어 있어
인터넷 연결만 있으면 어떤 기기에서도 그대로 열립니다.

## 담긴 내용

- **01 · 이야기의 뿌리** — 세계를 물들인 '만지는 수학'의 40년
- **02 · 경남 전역을 잇는 수학교육체험벨트** — 본원과 6개 수학체험센터 소개
- **03 · 수업과 맞물리는 가을 나들이 레시피** — 떠나기 전, 머무는 동안, 돌아온 후
- **04 · 수학 찾아 떠나는 스탬프 투어** — 참여 방법, 기념품, 기관별 안내
